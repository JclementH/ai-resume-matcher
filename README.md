# ResuMatch G

An `openrouter/free` AI-powered tool that evaluates how well a resume matches a job description.

## Features
- AI-powered analysis (OpenRouter)
- Structured scoring system
- Interactive UI with score visualization
- Persistent history (`localStorage`)
- Git hook automation for commit messages

## Tech Stack
- Frontend: React (Vite) + TypeScript + Tailwind
- Backend: Node.js + Express
- AI: OpenRouter
- Validation: Zod
